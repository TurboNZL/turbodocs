# App modules and file types

TurboDocs is one shell with separate apps inside it:

| Module | Opens |
|---|---|
| Docs | `.docx`, `.md`, `.markdown`, `.txt` |
| Sheets | `.xlsx`, `.csv` |
| Slides | `.pptx` |

**Settings › Apps** is where a module is installed or removed. A file is handed to the module for its type, whichever way you open it: the Open button, or "Open with TurboDocs" from your file manager.

**What exists today:** Docs is a **read-only viewer**: `.docx` (rendered with its fonts, colours, tables and images, without page breaks), Markdown and plain text. You can't edit or save yet. Headers and footers of Word documents are not shown. Sheets and Slides are planned and cannot be installed.
