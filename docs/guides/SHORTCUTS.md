# Shortcuts

## Everywhere
| | |
|---|---|
| Ctrl+O | Open a file |
| Ctrl+N | New document |
| Ctrl+S / Ctrl+Shift+S | Save / Save as |
| Ctrl+Alt+H | Back to Home |
| Ctrl+Q | Quit |
| F11 | Full screen |

## Docs
| | |
|---|---|
| Ctrl+B / I / U | Bold, italic, underline |
| Ctrl+Shift+X | Strikethrough |
| Ctrl+Shift+L / E / R / J | Align left, centre, right, justify |
| Ctrl+Alt+0 to 3 | Normal text, Heading 1 to 3 |
| Ctrl+Shift+7 / 8 | Numbered / bulleted list |
| Ctrl+] / Ctrl+[ | Indent / outdent a list item |
| Ctrl+Shift+. / , | Font size up / down |
| Ctrl+K | Link |
| Ctrl+\ | Clear formatting |
| Ctrl+F / Ctrl+H | Find / find and replace |
| Ctrl+Shift+C | Word count |
| Ctrl+Alt+W | Text width and margins |
| Ctrl+Shift+V | Paste as plain text (the other way round if "paste as plain text by default" is on) |
| Ctrl + mouse wheel | Zoom |

## Sheets
| | |
|---|---|
| Arrows, Shift+arrows | Move, select |
| Ctrl+arrows | Jump to the edge of the data |
| Ctrl+Home / Ctrl+End | First cell / last cell of the data |
| Enter / Tab | Next cell down / right (Shift: up / left) |
| F2 | Edit the cell |
| Delete | Clear values |
| Ctrl+D / Ctrl+R | Fill down / right |
| Ctrl+A | Select the data |
| Ctrl+B / I / U | Bold, italic, underline |
| Ctrl+F / Ctrl+H | Find and replace (Enter: next match) |
| Ctrl+K | Link on the selected cells |
| Alt+Shift+5 | Strikethrough |
| Ctrl+\ | Clear formatting |
| Ctrl+Shift+V / Ctrl+Alt+V | Paste values only / formatting only |
| Ctrl+Shift+4 / 5 / 1 | Currency / percent / number format |
| Ctrl+; | Today's date |
| Shift+F11 | New sheet |
| Ctrl+click (a linked cell) | Open the link |
| Right-click | Cut, copy, paste, insert, delete, sort, freeze |
| Delete (chart selected) | Remove the chart |
| Ctrl+Z / Ctrl+Y | Undo / redo |

## Slides
| | |
|---|---|
| Ctrl+F5 / Ctrl+Shift+F5 | Slideshow from this slide / from the beginning (F5 / Shift+F5 also work) |
| Ctrl+M | New slide |
| Ctrl+B / I / U | Bold, italic, underline (a selected text box) |
| Ctrl+Shift+L / E / R / J | Align left / center / right / justified |
| Ctrl+Shift+8 / 7 | Bulleted / numbered list |
| Ctrl+↑ / ↓ (Shift: to the front / back) | Bring forward / send backward; with no object selected, move the slide up / down (Shift: to the start / end) |
| Enter | Edit the selected text box |
| Delete | Delete the selected objects |
| Arrows (Shift: ×10) | Nudge the selected objects |
| Shift+click, drag on the background | Add to the selection, select a rectangle |
| Ctrl+A | Select every object on the slide |
| Alt (while dragging) | Move without snapping to guides |
| Shift (while turning) | Turn in steps of 15° |
| Ctrl+D | Duplicate |
| Ctrl+C / X / V | Copy, cut, paste objects |
| Tab (in a table cell) | Next cell |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Esc | Deselect, or leave the show |
